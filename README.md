
# FASTSPOTS

Fastspots is a web application build using NEXT.js framework. It uses the Spotify API to handle OAUTH2 login to your Spotify account. In the application you can see your top tracks and artists. There is also a playlist editor which allows for editing multiple playlists at once in a faster manner then Spotify allows and creating playlists has never been this fast. 


## How to try

Unfortunetly I added the option to control the Spotify music player from my application also, and this was a not allowed feature by Spotify so they didn't give my app the rights to be run by anyone. So it can only be run by selected users currently. 

The app is hosted to www.fastspots.net, but the authentication won't work for this reason. 

One way to try the application is to create your own Spotify developer account and then clone this git repo and insert your own spotify access codes and secrets in the env file.
